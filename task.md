Take-Home Assignment — AI Chatbot (Automotive Domain)

🎯 Task Overview

You are asked to design and implement a proof-of-concept AI chatbot that helps users understand and compare cars based on real automotive review content.

The goal of this assignment is NOT to build a production-ready system, but to demonstrate:
• Your ability to work with unstructured real-world text
• Clear architectural thinking
• Practical use of LLMs / NLP techniques
• Sensible trade-offs and explanations

🧩 High-Level Description

The chatbot should be able to:
• Ingest and understand automotive review articles
• Build a searchable knowledge base from that content
• Hold a natural, user-friendly conversation
• Gradually infer user preferences
• Respond based on retrieved knowledge rather than hallucination

You are free to choose your tools, frameworks, and models.

🧠 Expected Capabilities (at a high level)

Your solution should demonstrate:
• Text ingestion and processing
• Knowledge retrieval (e.g., vector search, indexing, or similar)
• Grounded responses based on retrieved content
• A conversational interface (CLI / API / UI — your choice)



🧪 What to Submit

• Code (repository or archive)

• Example interaction with the chatbot

Focus on clarity, reasoning, and decision-making rather than completeness.
